# Tag results

Returns the tag results for a given flow.

|             |                             |
| ----------- | --------------------------- |
| Rest API    | `GET result/{result-id}/tag-results-of-flow/{envi-flow}` |
| JSON-RPC    | `result/tag-results-of-flow` |
| Snake case  | `result.get_tag_results_of_flow` |
| Camel case  | `result.getTagResultsOfFlow` |
| Return type | [`List[TagValue]`](http://greendelta.github.io/olca-schema/classes/TagValue.html) |
| Parameter 1 | [`EnviFlow`](http://greendelta.github.io/olca-schema/classes/EnviFlow.html) |
