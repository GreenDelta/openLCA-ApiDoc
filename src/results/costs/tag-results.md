## Tag results

Returns the tag results for the calculated LCC results.

|             |                             |
| ----------- | --------------------------- |
| Rest API    | `GET result/{result-id}/tag-results-of-costs` |
| JSON-RPC    | `result/tag-results-of-costs` |
| Snake case  | `result.get_tag_results_of_costs` |
| Camel case  | `result.getTagResultsOfCosts` |
| Return type | [`List[TagValue]`](http://greendelta.github.io/olca-schema/classes/TagValue.html) |
